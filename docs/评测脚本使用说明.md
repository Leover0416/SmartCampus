# 评测脚本使用说明

项目内置两类测试，用于生成简历/论文可用的量化指标。

---

## 一、指标报告（与数据看板一致）

**作用**：从 `agent_logs` 打印 FAQ 命中率、知识库命中率、引用率、FAQ vs 全链路 P95 延迟等。

### 步骤

1. 启动 Docker 中间件 + MySQL + 后端 + 前端（见 README）
2. 用 **student001** 登录，在对话页多问几轮，例如：
   - FAQ：「本学期什么时候选课」「挂科了怎么办」
   - RAG：「奖学金评定标准」「学校相关政策」
3. 在项目目录执行：

```bash
cd campus
export BAILIAN_API_KEY=sk-你的密钥   # 若已写入 ~/.zshrc 可省略
mvn test -Dtest=EvalMetricsReportTest
```

### 输出示例

```
========== SmartCampus 评测报告（近 30 天）==========

一、与数据看板一致的核心指标
  FAQ 命中率 faqHitRate:           28.5 %
  平均响应耗时 avgResponseMs:      4521 ms
  ...

二、FAQ 短路 vs 完整 RAG 延迟对比
  FAQ 短路：n=12  avg=186 ms  P95=210 ms
  完整 RAG：n=25  avg=7635 ms  P95=8200 ms
```

这些数字可直接改写进简历（注明样本量 n）。

## 二、离线召回评测（FAQ + Recall@3）

**作用**：不经过前端，直接测 FAQ 短路和 RAG 前 3 条检索是否命中预期关键词。

### 前置

- MySQL 已导入 `campus.sql`（含 `faq_pairs`）
- Redis、Milvus、MinIO 已启动
- 知识库最好已有文档（否则 RAG 用例会 FAIL）

### 运行

```bash
cd campus
export BAILIAN_API_KEY=sk-你的密钥
mvn test -Dtest=RagRecallEvaluationTest -Deval.integration=true
```

### 扩充评测集

编辑 `src/test/resources/eval/eval-questions.json`：

```json
{
  "id": "faq-06",
  "query": "你的问题",
  "type": "FAQ",
  "expectContains": "答案里应包含的词"
}
```

```json
{
  "id": "rag-04",
  "query": "你的政策问题",
  "type": "RAG",
  "expectDocKeyword": "文档标题或正文应含的关键词"
}
```

建议扩充到 **30～50 条** 后再写论文/简历。

## 三、Python 批量对话评测（替代手点前端）

**作用**：自动登录 → 逐条调用 SSE `/api/v1/chat/stream` → 统计延迟与通过率，写入 `reports/`。

**依赖**：Python 3.9+（标准库即可，无需 pip）

```bash
cd campus
python3 scripts/batch_chat_eval.py
python3 scripts/batch_chat_eval.py --questions scripts/questions-batch.json --delay 2
python3 scripts/batch_chat_eval.py --limit 5 --output reports/smoke.json
```

| 参数 | 说明 |
|------|------|
| `--base-url` | 默认 `http://localhost:8080` |
| `--username` / `--password` | 默认 `student001` / `student123` |
| `--questions` | 默认 `scripts/questions-batch.json`（20 条） |
| `--new-session-each` | 每条新会话；默认共用一会话 |
| `--delay` | 间隔秒数 |

输出：`reports/batch-*.json` + 同名 `.csv`。跑完再执行 `mvn test -Dtest=EvalMetricsReportTest` 对照看板。

## 四、与数据看板的关系

| 看板指标 | 数据来源 | 评测脚本 |
|----------|----------|----------|
| FAQ 命中率 | `agent_logs.hit_docs='FAQ'` | `EvalMetricsReportTest` 第一节 |
| 知识库命中率 | `hit_docs` 非空且非 TOOL | 同上 |
| 引用率 | `chat_messages.source_refs` | 同上 |
| 平均响应 | `avg(total_ms)` | 同上 + 第二节 P95 |
| Recall@3 | 需标注集 | `RagRecallEvaluationTest` |

看板 API：`GET /api/v1/dashboard?days=7`（需教师/管理员登录）。

## 五、常见问题

**Q: EvalMetricsReportTest 全是 0？**  
A: `agent_logs` 无数据 → 先在对话页提问。

**Q: RagRecallEvaluationTest 被跳过？**  
A: 必须加 `-Deval.integration=true`。

**Q: FAQ 评测 FAIL？**  
A: 问题与 `faq_pairs` 表述差异大 → 改 `eval-questions.json` 或调低 `faq.match.exact_thresh`（系统设置）。

**Q: RAG 全 FAIL？**  
A: Milvus 无向量 / 未上传文档 → 先在知识库上传 PDF 并等「已就绪」。
